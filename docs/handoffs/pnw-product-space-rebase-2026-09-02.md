### Required contracts and behavior

Define closed, versioned `RegionPack`, `CommunityDeploymentProfile`,
`PersonaProjection`, `CommunityRelevanceAssertion`,
`ProjectedRecordReference`, `DeploymentView`, `EngineProjection`, and a narrow
generic `OutputAdapter<T>` interface. The first version supports only
repository-authored synthetic profiles, public visibility, exact known
source/taxonomy references, and deterministic configuration rules such as a
synthetic watchlist. Reviewed geography, rights frames, analyst judgment,
organization priorities, legal conclusions, and real community authority are
unsupported rather than inferred.

| Interface/schema | Minimum first-tranche boundary |
| --- | --- |
| `RegionPack` | Stable ID and version; exact source IDs, taxonomy-version IDs, and authority-qualified jurisdiction references. |
| `CommunityDeploymentProfile` | Stable ID and version; `synthetic_demo` or `candidate` authority state; one region-pack ID; deterministic watch-rule references. |
| `PersonaProjection` | Stable ID and version; public-only visibility in this tranche; output-adapter IDs that cannot alter facts. |
| `CommunityRelevanceAssertion` | Typed allowed basis; rule/configuration ID and version; evidence reference; review state; temporal scope; explicit non-claims. |
| `ProjectedRecordReference` / `DeploymentView` | Record ID references only, grouped by deployment/persona; no copied or mutated `PolicyRecord`. |
| `EngineProjection` | One unchanged `PolicyRecord[]` plus deterministic reference-only views. |
| `OutputAdapter<T>` | Stable adapter ID/version and a pure `produce(projection, viewId)` boundary; no concrete output adapter in this tranche. |

The JSON Schema applies to the synthetic region/deployment/persona profile
bundle. Runtime TypeScript must parse that validated shape into readonly
contracts, reject unknown references and duplicate IDs, and avoid imports from
presentation, source-adapter, K0, S0, or O0 modules.
