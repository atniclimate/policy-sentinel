# Grants.gov

The demo searches forecasted and posted opportunities. The detail reader can show a short passage under an authority heading when the synopsis supplies one. Check the originating agency's announcement for conditions, deadlines and eligibility.

The API terms permit searching and displaying opportunity data. The demo withholds general synopsis summaries. Linked announcements and attachments carry their own terms. This product uses the Grants.gov API but is not endorsed or certified by the U.S. Department of Health and Human Services. [Grants.gov API guide](https://www.grants.gov/api/api-guide) and [API terms and conditions](https://www.grants.gov/api/terms-conditions).
