# Congress.gov

Use a bill's Congress, type and number to look up its title, latest action and official page. The Library of Congress maintains Congress.gov. Coverage varies by field and Congress.

The demo displays bill metadata and links. It withholds Congressional Research Service summary bodies pending field-specific review. Attribute the listing to Congress.gov, Library of Congress. [Congress.gov API](https://api.congress.gov/) and [Library of Congress copyright guidance](https://www.loc.gov/legal/security-copyright-and-privacy/understanding-copyright/).
