# OLRC United States Code in USLM XML (static index source)

Accessed: 2026-11-19 (Pacific). Owner approval of this use: D-134 (OLRC terms
accepted for the U.S. Code index shard, 2026-11-06), D-125 (the index
conditions, `docs/development/full09-index-conditions-2026-11-05.md`) and
D-190 (the fetch, 2026-11-19).
Terms reading: the 2026-11-06 review of uscode.house.gov (no terms page; the
robots file blocks only one named crawler; visits are logged under the privacy
policy). The manifest's rights record therefore reads `none stated`, with the
download page as its address.

## What it is

The United States Code as published by the Office of the Law Revision Counsel
of the U.S. House of Representatives, one zip of USLM XML per title at a named
release point.

- Download page: https://uscode.house.gov/download/download.shtml
- Title zip:
  `https://uscode.house.gov/download/releasepoints/us/pl/{congress}/{law}/xml_usc{title}@{releasePoint}.zip`
- Release point used: 119-142. Each file states "Online@119-142" and "Current
  through 119-142", and the builder refuses a file that states anything else.

## Fields used

For each section: its identifier, its status as the Code states it
(transferred, repealed, omitted, reserved or none), the source credit's wording
and its references (public laws, Statutes at Large, acts). For a transferred
section only: the words of its codification note, or of its removal note when
it has no codification note, and the U.S. Code sections that note links. Not
used: section text, headings, and every other note.

A transfer is carried in the Code's own words. A link to a subsection is kept
at its section; a note that names the new home only in prose is quoted with no
link; nothing is read out of the prose. A classification or transfer note is
the Office's editorial statement, and a row says nothing about legal effect.

## Access

- Authentication: none. No key, account or click-through.
- Rate limits: none stated. This use is one request per address, at least 1.1
  seconds apart, no retry.
- Reuse: no restriction found on the pages read on 2026-11-06. The Code is a
  work of the federal government (17 U.S.C. 105). Rows name the Office of the
  Law Revision Counsel as the source; no seal or logo is used.
- Cadence: a new release point after new public laws are classified. The
  freshness report reads the download page when run with `--olrc-terms-read`.
- CORS: not relevant. The fetch runs in a session; the page never calls OLRC.

sections ("466...466g") with up to 10 linked sections and a note of about

Title 33 was built from its kept download after the builder fixes, through
the same acquisition code and with no second request; its manifest entry
carries the time of the original request.

## Known failure behavior

The builder fails a whole title, and writes nothing, on a section status
outside its closed list, a transferred section with neither note, or a file
whose release point wording differs from the one requested. The manifest then
records the stage and the message, and the page says the index is not
available and links the Office's own page.
