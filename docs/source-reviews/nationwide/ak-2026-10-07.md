# Alaska SourceDescriptor draft

Review date: 2026-10-07. Work item: GD-17-NATIONWIDE-SOURCE-SURVEY.
This jurisdiction document is a documentation-only collection of source-family
candidates, not one executable multi-authority descriptor. Split rows into
source-specific descriptors only after exact originating authority and contracts
are qualified. The [regional evidence and boundary record](regional-2026-10-07.md)
defines the evidence labels, proposed public allowlist, privacy exclusions,
unknown access/reuse conditions, fixture needs and fail-closed health behavior;
those limits apply to every row here.

## Draft catalog fields

| SourceDescriptor field | Proposed value or unresolved prerequisite |
| --- | --- |
| id | Documentation namespace `gd17-ak-2026-10-07`; not a registered source ID. Per-class suffixes `legislation`, `codes`, `rules-registers`, `opinions`, `local` identify matrix candidates only. |
| authority class | State rows: `state`, preserving separate legislature, executive publisher and court. Local rows require their own county/municipal issuing authority; the state is not their issuer. |
| publishing jurisdiction | Proposed state reference `us-state:AK`; no new registry binding or FIPS verification is made here. Local publisher references require separate exact jurisdiction evidence; no Nation association is assigned. |
| interface kind | Documentation/index `html` and source-described interfaces in the matrix; no linked PDF/body or API data was acquired. An index description is not a stable machine contract. |
| hosts and path prefixes | Evidence URLs below are locators, **not** a dispatch allowlist. Authorized acquisition hosts/path prefixes: empty. No broad host approval or invented endpoint. |
| review | Reviewer: GD-17 regional source-scout; reviewedAt: 2026-10-07. Retained evidence has its own row dates. expiresAt: not assigned because no live clearance is granted; every successor needs a bounded fresh review. evidenceUrls: cited per row. |
| uses | Accepted acquisition/output uses: empty. Proposed metadata-only fields in the regional record are minimization intent, not a reuse license. Text/body/excerpt/export acceptance: none. |
| cadence | Source-specific statements below; otherwise unknown. No product polling cadence selected. |
| credential requirement | Only `none` could enter a later public-source contract while EXT-CREDENTIALS is closed. Known credential/terms requirements remain blocked; unknown requirements cannot be silently represented as none. |
| range and state | Documented/observed ranges are row-specific, noncomprehensive unless explicitly documented. Selected build range: none. Emitted range: none. Disposition: evidence blocked unless the row explicitly states terms/credential blocked. Not admitted, not activated. |

## Next contract evidence

Apply each row's exact gap before treating a locator as a viable interface.
Verify source policies, credential/access conditions, permitted exact fields and
intended uses, canonical identifiers, revision/status/date semantics, bounded
pagination or finite inventory, historical completeness and failure behavior.
The eventual descriptor must name attribution to the originating publisher and
a fresh review expiry, exact paths and budgets. Unknown rate, robots, bulk-use or
text rights remain unknown, not permission. CORS was not tested and supplies no
browser dependency. A failed research-tool request is not proof of host denial.

The [regional pilot discussion](regional-2026-10-07.md#narrow-pilot-contract-preparation-option)

profile or inherits an expired request grant. A later source fixture/adapter
