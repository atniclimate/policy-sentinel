# Initial public Tribal and intertribal source matrix

Reviewed 2026-10-07 by the root source-review lane for GD-17. Documentation and
index review only. See the [integrated survey](../../development/gd17-initial-source-survey-2026-10-07.md)
for authority, pilot selection, API acceptance and storage dependencies.

These prose SourceDescriptor drafts distinguish each issuing government/body.
Names below are source-selection labels, not installed Nation configuration,
recognition evidence, registry bindings, ATNI membership claims, or inferred
Nation-record relationships. Selected state headings organize planning only;
they do not establish territory, land interests or jurisdiction boundaries.

## Shared draft contract

Authority classes are `intergovernmental` for organizational resolutions and
`tribal_government` for originating public government publications. Candidate
interface kinds are HTML indexes and linked documents (PDF/HTML where stated).
Hosts and exact index paths below are documentation locators, **not an
allowlist for acquisition**. No active descriptor ID, profile expiry, operation
manifest or request/byte/retry budget is created. Review date is 2026-10-07;
review must be renewed source-by-source before any successor dispatch. Binding
jurisdiction identifiers remain unresolved under the future registry contract.

Observed public access does not establish capture, excerpt, redistribution,
export or republication rights. Those uses are unqualified for every new row.
No credential was supplied or registered. Absence of a login on an index is not
proof that all linked documents are credential-free. APIs, machine pagination,
rate limits, CORS, robots, format maxima and refresh schedules are unverified
unless expressly stated. All access is build-time under a future contract;
there is no browser dependency on these publishers.

The proposed projection permits only source-stated publisher/issuer, exact
record identifier, title, canonical official link, instrument/body/type,
source-stated status and separate adoption/publication/version dates, exact
subject labels, field provenance, retrieval time and available source update
time. Missing facts remain missing. This is a proposed allowlist, not permission
to publish those fields. Preserve source wording; no legal-effect finding or
keyword/AI category. Unmapped categories remain Unclassified.

Exclude preparer/staff/contact details, signatures, comments, application forms,
personnel and individual case data, sensitive cultural/land information,
credentials, unrelated attachments and private research/annotations. Do not
save full index HTML merely to obtain a few permitted fields. Public
administrative subject matter is eligible under D-087; it does not override
field-level privacy, restrictions on internal records, or reuse conditions.

## Fixture, health and activation requirements

Future source-specific fixtures must cover missing/malformed identifiers, URLs,
dates and status; indexed passed versus tabled conflicts; proposed versus
adopted/emergency/consolidated text; amended/withdrawn status; USET versus SPF
and Assembly versus Executive Council collisions; reused identifiers with
changed bytes; redirects/delegated hosts; truncated or unenumerated indexes;
malformed HTML/PDF; and accidental contact, private-note or land-field
inclusion. No fixtures or tests for these sources were implemented here.

Initial runtime health is not installed. Research reachability is separate
from operational source health. A future failure must be isolated per source;
reuse only checksum-validated prior public output of the same adapter, retain
its original data-as-of time and mark stale/degraded. With no such accepted
shard, omit source output and mark unavailable. All new rows currently lack an
accepted last-known-good shard. No cross-publisher substitution, silent retry,
freshness relabeling or inferred completeness is allowed.

Before dispatch, GD-31 and source owners must resolve current terms/rights and
any actual credential/access gates, verify exact documents and status, define
hosts/paths/format/request/retry/byte/custody/output boundaries, and obtain
independent contract review. GD-18 measures total managed storage; later
canaries and fixtures validate transport, fields, projection and failure paths.
No selected build date range or corpus weight is measured here; archive labels
above are not acquisition ranges. Existing profiles, gates and consumed
budgets remain unchanged.
