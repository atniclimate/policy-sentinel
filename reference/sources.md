# Source coverage and reuse

Use **About and Limits** in the demo to see which sources can answer a search. Each result carries its source identifier and official link. The notes below explain what each listing covers and which text the reader may display.

In the local workspace, the source catalog dates each review and links to the official material consulted at the time. A catalog entry records that review. Retrieval requires a separately enabled source.

The static lookup index includes selected U.S. Code and CFR titles and Federal Register vocabularies. Its manifest identifies the included files and generation date. A citation outside those selected titles can still refer to an official record. [Index manifest](../docs/demo-data/manifest.json).
